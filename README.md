### 夕凪の街角

红白双节电车沿钢桁架高架驶过。桥下的拉面摊亮着暖灯，马路对面的贩卖机把桥墩染成淡青色。镜头绕到街面一侧，可以透过玻璃看见书架、咖啡店的座位和便利店的货架。

- 晴暮时，斜阳擦过屋檐和车顶，地块边缘与轨道渐渐没入雾中。
- 切到雨天，细雨打在沥青上，店招和窗灯映在湿路里，电车前灯沿着枕木向前扫过。
- 建筑、车辆、招牌和场景纹理由代码生成，场景和交互收在同一个 HTML 文件里。

### 黑洞与紫罗兰

暖金色的吸积盘横过地平线，紫罗兰在风中起伏。一位宇航员立在花海里，静静望着光环。

![《黑洞与紫罗兰》实机画面，金色吸积盘下的宇航员站在紫罗兰花海中](./black-hole-and-violets/preview.jpg)

## 本地运行

### 运行《夕凪の街角》

1. 点作品表里的 **单文件 HTML**，再点 GitHub 文件页右上方的下载按钮 **Download raw file**。
2. 保持联网，双击下载的 `yunagi-street-tram-shadows.html`。页面会通过 CDN 加载 Three.js。
3. 拖动旋转，滚轮缩放，右键拖动平移。用页面上的按钮切换天气、暂停动画或重置视角。

想复现场景时，可以复制作品表里的完整提示词，交给编程 AI 生成自己的版本。提示词交代了街区摆位、列车、晴雨光影和雾的过渡。

### 运行《黑洞与紫罗兰》

下载或克隆仓库后，用 Node.js 18 或更新版本启动场景。滚轮、双指捏合和 `+`、`-` 可以调整焦距。

```sh
cd black-hole-and-violets
node serve.mjs
```

用支持 WebGL 2 的浏览器打开场景。[本地预览](http://127.0.0.1:4173/) · [完整运行说明](./black-hole-and-violets/README.md)
